SF III Ryu animation source

Character / game artwork: CAPCOM.
MUGEN character author: Umihei (SF3_Ryu.def).
Archive retrieved from: https://github.com/Tatayecorp/demo_mugenJS
Source revision: 487db4c65971bd7173b621d09dc5c4129433e6ed

Imported from chars/SF3_Ryu/Ryu.sff and CODE/Ryu.air.
All 1,285 SFF sprite entries and 712 AIR action definitions are preserved in
the atlas pages and animations.json, including effects and variants.
The runtime uses a selected set of complete movement and combat sequences,
with the original pixels, anchors, per-frame timing and hit/hurt boxes.
The JavaScript AI and magic interaction rules are specific to this game;
this is not a full emulation of the original MUGEN command/state engine.
Fourteen unresolved sprite references already exist in source AIR actions
not used by this game's combat. They are recorded in animations.json.
The legacy laughter and seated-rest assets remain archived in actors.png but
are no longer used for Ryu reactions. Normal hit expressions use newly
generated edits based on SF3 poses; defeat uses original fall/down frames.
The four-frame purple-ring binding animation is newly generated artwork
referencing the imported SF3 Ryu appearance; it is not an original CAPCOM
or Umihei animation.

The repository's software is MIT-licensed; that license is not represented
as a separate grant for CAPCOM character or game-art rights.

Alternate shirtless costume sheets are newly generated adaptations for all
255 character sprite references used by runtime clips, plus the binding,
bound laughter and normal-hit sheets. They preserve the imported action
timing, collision data and pivot mapping, but are not original CAPCOM or
Umihei artwork. The wizard melee sheet is newly generated prototype artwork.
