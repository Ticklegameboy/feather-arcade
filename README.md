# 羽夜奇譚 · Feather Arcade

Three-language browser arcade fan game. No build or API key required.
Click to cast binding magic and move the feather cursor to interact. Sound is on by default after starting; use the sound button to mute. Progress is saved in the current browser.

GitHub Pages: publish the main branch, / (root).

Unofficial fan project. Character artwork: CAPCOM; combat sprites / AIR data: Umihei via Tatayecorp/demo_mugenJS. See ryu--CREDITS.txt, ryu--audio--CREDITS.txt and background--CREDITS.txt. Third-party assets retain their respective ownership.
