# 羽夜奇譚 · Feather Arcade

Browser arcade fan game. Play in Traditional Chinese, English or Japanese.

Click to cast binding magic; move the feather cursor to interact with bound enemies. Earn laughter, learn new magic and visit the dungeon prisoners. Sound is enabled with the sound button. Progress is saved in the current browser.

This repository contains the runnable website source and assets. No build or API key is required. GitHub Pages: deploy the `main` branch from `/ (root)`.
